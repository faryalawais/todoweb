# To Do Web

A web application for managing to-do items using NestJS, React, and Supabase.

## Getting Started

### Prerequisites
- Node.js
- npm

### Installation
1. Clone the repository:
   ```
   git clone https://github.com/faryalawais/todoweb.git
   cd todoweb
   ```
2. Install dependencies:
   ```
   npm install
   ```

### Running the Application
- To start the application:
  ```
  npm run build
  npm start
  ```

### Running Tests
- To run unit tests:
  ```
  npm run unit
  ```
